1. Respon a les següents preguntes en un document HTML de nom “respostes.html” :

a. Sobre el display INLINE-BLOCK

  1. Cóm podem situar una caixa al costat de l’altre?

      2. Amb display:inline-block, les caixes es col·loquen en línia dins del mateix contenidor.

  2. Què passa si una caixa no hi cap al costat?

      3. La següent caixa baixa a la línia inferior automàticament.

  3. Perquè serveix la propietat “vertical-align”?

      4. vertical-align: Serveix per ajustar l'alineació d'elements inline o inline-block.

  4. Com podem centrar una caixa dins d’una altre?

      5. Usa text-align:center al contenidor i display: inline-block a la caixa interior.

b. Sobre el display FLEX-BOX

  1. Cóm podem crear files?

      2. Establint la direcció del contenidor com a fila (row), els elements fills es disposen horitzontalment.

  2. Perquè serveix flex-wrap?

      3. Permet que els elements es desplacin a una nova línia si no hi caben en una sola.

  3. Perquè serveixen les propietats flex-grow, flex-shrink i flex-basis?

      4. flex-grow: controla com creix un element per ocupar espai extra.

      flex-shrink: determina com es redueix quan no hi ha prou espai.

      flex-basis: defineix la mida inicial de l’element abans de distribuir l’espai.

c. Sobre el display GRID-LAYOUT

  1. Cóm indiquem el número de files i columnes de la grid?

      2. Es defineixen amb propietats específiques per files i columnes, indicant quantes i de quina mida.

  2. Cóm indiquem quantes files i/o columnes ocupa una àrea de la grid?

      3. Es fa amb propietats que especifiquen l’inici i el final de la fila o columna que ocupa l’element.

  3. Què indiquen colom-gap i el row-gap?

      4. L’espai entre columnes i entre files, respectivament.

  4. Què indica la propietat grid-area?

      5. Assigna un nom o una posició específica a un element dins la graella, útil per organitzar-lo segons una plantilla.
